# Trending Blockbusters (Movie Cards Showcase)

A modern, visually stunning, and fully responsive Movie Showcase interface built with semantic HTML5 and Vanilla CSS3. Developed as part of the **MERN Impact** training program, this project demonstrates clean layout styling, CSS Grid, CSS Flexbox, and modern design principles.

## ✨ Features

- **Modern Dark Aesthetics**: Sleek `#0b0f19` deep blue background paired with high-contrast font combinations and curated glow gradients.
- **Dynamic Flex & Grid Layouts**: Responsive grid wrapper designed with `auto-fill` and `minmax` logic to fit any viewport screen size.
- **Glassmorphism Badges**: Custom stylized rating (`★`) and genre badges with semi-transparent background tints matching their category.
- **Micro-Animations & Transitions**:
  - Cards elevate and grow custom shadow glows on hover.
  - Image scaling effects within card containers.
  - Tactile button press feedback (`transform: scale(0.98)`).
- **Responsive Theme Shift**: Integrates media queries that change title accents dynamically based on device widths.
- **Clean Semantic Markup**: Written with HTML5 elements (`<header>`, `<section>`, `<a>`) for accessibility and search engine optimization.
